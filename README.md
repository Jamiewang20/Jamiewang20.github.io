# 王建明 / Jamie Wang

Personal website, Smart Note bilingual blog, and ReSpark podcast.

- Chinese: https://jamiewang20.github.io/
- English: https://jamiewang20.github.io/en/
- 65 articles in each language, with original illustrations and reading layouts.

The website is static HTML, CSS and JavaScript. All page files and images are stored in this repository. No ChatGPT session or original Site is required to visit the imported website.

GitHub Pages publishes the `main` branch's root folder. `.nojekyll` preserves the static output. Future edits to these files are published by GitHub Pages.

`.migration/` records the source snapshot and its file hashes. The import workflow runs only when migration files change or when manually requested; after import it uses the files already committed here. Original article references and externally hosted video links are retained.
